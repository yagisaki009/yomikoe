# よみこえ

AIの自然な声で、長い文章を読み上げるiPhone向けのWebアプリです。字数の上限はありません。
声は2種類から選べます。

| | Gemini（Google） | Grok（xAI） |
|---|---|---|
| 料金 | 無料（1日・1分あたりの回数に上限あり） | 100万字あたり15ドル |
| 声の数 | 30種類（女性14・男性16） | 26種類 |
| 表現の指示 | 間・息つぎ・ため息、読み方の雰囲気を言葉で指示 | 間・息つぎ・ささやき・ため息など |

## 使い始めるまで

### 1. APIキーを作る

**Geminiの場合（おすすめ・無料・カード不要）**

1. [Google AI Studio のAPIキーのページ](https://aistudio.google.com/apikey) をGoogleアカウントで開きます。
2. 「APIキーを作成」を押し、**「新しいプロジェクトで作成」**を選びます。
   お支払い情報（クレジットカード）を登録したGoogle Cloudのプロジェクトで作ると、無料枠ではなく有料になります。
3. 表示されたキー（`AIza` で始まる文字列）をコピーします。
4. その日に使える回数は、AI Studioの「使用量とレート制限」で確認できます。使い切ると、日本時間の16〜17時ごろに回復します。
5. 「有料（前払い）の設定になっていて、前払いの残高が0」と出たときは、そのキーのプロジェクトにお支払い情報が付いています。[Google Cloudのお支払いのページ](https://console.cloud.google.com/billing/projects)で、そのプロジェクトの課金を無効にすると、同じキーのまま無料枠に戻ります。同じお支払い情報につながった新しいプロジェクトでキーを作っても、有料のままなので注意してください。

**Grokの場合**

[console.x.ai](https://console.x.ai) でアカウントを作り、クレジットを購入してから「API Keys」でキーを発行します。

<a id="elevenlabs"></a>
**予備：ElevenLabsの声（Geminiを使い切ったあと用）**

Geminiの無料枠を使い切ったときに使います。無料プランなら月1万字ほど（1,500字の話で6〜7話）、有料プランなら契約した分まで使えます。

1. [elevenlabs.io](https://elevenlabs.io)で「Sign up」を押し、Googleアカウントかメールアドレスで登録します（無料プランのまま使います）。
2. 左下の自分の名前（アカウント）のメニューから「API Keys」を開き、「Create API Key」を押します。
3. 許可の欄は、「Text to Speech」を「Access」に、「Voices」「User」「History」を「Read」にします（Userは、残りのクレジットをよみこえに出すため。Historyは、通信が切れたときに作り直さず、ElevenLabsの履歴から受け取るため。作り直すと、同じ部分でクレジットを二重に引かれます）。ほかはそのままでかまいません。有料プランのときは、使いすぎを防ぐため、キーのクレジットの上限（Credit limit）も入れておくと安心です。「Create」を押すと `sk_` で始まるキーが一度だけ出るので、コピーします。
4. 日本語の声を使うときは、左のメニューの「Voices」→「Explore」で言語を「Japanese」にしぼり、好きな声を自分の一覧に追加します（一部の声は有料プランだけです）。
5. よみこえの設定の「無料枠を使い切ったとき」で、ElevenLabsの欄にキーを貼り付けます。声の一覧が出たら選び、「試聴」で声が出れば完了です。欄の中に、残りのクレジットと、戻る日が出ます。

ElevenLabsの画面の言葉は、変わっていることがあります。見つからないときは、近い名前のものを探してください。

<a id="microsoft"></a>
**予備：Microsoftの声（Geminiを使い切ったあと用・無料）**

Geminiの無料枠（3.8 Flashと3.8 Flash Liteで、それぞれ1日10回ほど）を使い切ったあと、Microsoftの声で続けるためのキーです。月50万字（1,500字の話で約330話）まで無料です。

1. [Azureの無料アカウントのページ](https://azure.microsoft.com/ja-jp/free/)で「無料で始める」を押し、Microsoftアカウントでサインインします。電話番号とクレジットカードの登録を求められます（本人確認のためです）。
2. [Azureポータル](https://portal.azure.com)を開きます。上の検索欄に「Speech」と入れ、出てきた「Speech サービス」を開いて「＋ 作成」を押します。
3. 作成の画面で次のように選び、「確認と作成」→「作成」を押します。
   - サブスクリプション：そのまま
   - リソース グループ：「新規作成」を押して、好きな名前（例：yomikoe）
   - リージョン：Japan East
   - 名前：好きな名前（例：yomikoe-voice-123。ほかの人と同じ名前は使えません）
   - 価格レベル：**Free F0**（必ずこれにします。F0は無料の分を使い切ると止まるだけで、料金はかかりません）
4. 作成が終わったら「リソースに移動」を押し、左のメニューの「キーとエンドポイント」を開いて、「キー 1」をコピーします。
5. よみこえの設定の「無料枠を使い切ったとき」にキーを貼り付け、地域で「東日本（Japan East）」を選びます。「試聴」で声が出れば完了です。はっきりしすぎると感じたら、「落ち着いた読み方」に印を付けてください（少しゆっくり・低めに読みます）。

注意：Azureの無料アカウントは、登録から30日たつと「従量課金制」への切り替えを求められ、切り替えないと作った音声サービスが止まります。切り替えても、価格レベルがFree F0の音声サービスだけなら料金はかかりません。ほかのサービスは作らないでください。

### 2. このフォルダをネットに置く（GitHub Pages・無料）

1. [github.com](https://github.com) でアカウントを作る
2. 新しいリポジトリを作る（Public）
3. 「uploading an existing file」から、このフォルダのファイルをすべてドラッグして保存
4. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
5. 数分後に表示される `https://〜.github.io/〜/` がアプリのURL

### 3. iPhoneに入れる

SafariでそのURLを開き、共有ボタン →「ホーム画面に追加」。

### 4. APIキーを入れる

アプリ右上の設定ボタンを開き、「音声の種類」を選んでキーを貼り付けます。キーはiPhoneの中にだけ保存され、GoogleやxAI以外には送られません。
Geminiは「読み方の雰囲気」に「静かに、低い声で語るように」のように書くと、声の調子が変わります。

## 料金の目安

- **Gemini**：無料。文字数ではなく、1日・1分あたりの回数に上限があります（声のモデルごとに1日10回ほど）。回数を節約するため、1回目のあとは段落をまとめて大きめに送ります。
- **Microsoft（予備）**：Free F0なら月50万字まで無料。超えると止まるだけで、料金はかかりません。
- **ElevenLabs（予備）**：無料プランなら月1万字ほどで、超えると止まるだけです。有料プランは契約した分まで使え、「使いすぎた分も払う」設定にしていると料金が増えます。
- **Grok**：1ドル150円なら、月1,000円で約44万字。設定の「月の上限」を超えそうになると、自動で止まります。
- どちらも、一度作った段落はiPhoneに保存されるので、聞き直しは無料です。
- 保存できる量は、設定の「保存の上限」で1〜10GBから選べます（最初は3GB）。Geminiの音声は届いた後でMP3に圧縮して保存するので、1時間で約29MB、3GBで約110時間分です。上限を超えると、古い音声から消えます。
- アプリの数字は、このiPhoneで使った分から出した目安です。正確な金額はGoogle CloudやxAIの管理画面で確認してください。

## コツ

- **読み間違い**：設定の「読み方の辞書」に `怪異=かいい` のように登録
- **ルビ**：`漢字《かんじ》` や `｜漢字《かんじ》` の形式は、自動でルビの読みを使います
- **表現**：入力欄の下のボタンで指示を入れられます。ささやき・やわらかく・ゆっくりはGrokだけで使えます
- **台本**：「💴📙の題名」と「───」の区切り線がある台本は、題名と本文だけを読みます。■5行要約・■あとがき・■概要欄用タイトル（【短】【長】）などは飛ばします（設定の「台本の読み方」で変更でき、あとがきだけ読むこともできます）
- **Geminiの回数を節約する**：1日に送れるのは、声のモデルごとに10回ほどです。設定の「回数を節約する」がオン（最初からオン）なら、2,000字ほどまでの話を1回で作ります（1,500字の話なら1回、8,000字のアルバムなら4回）。そのかわり、押してから鳴るまで、話を作り終えるのを待ちます（数十秒ほど）。前もって「端末に保存」しておいた話は待ちません。すぐ鳴らしたいときはオフにすると、最初の250字ほどを別に作ってすぐ鳴らします（1,500字の話で2回）。入力欄の下の「Geminiに送る回数」で、読む前に確かめられます
- **無料枠を使い切ったとき**：無料枠の回数は声のモデルごとに別々です。いつもの3.8 Flashを使い切ると、同じ声・同じ「読み方の雰囲気」のまま、軽い3.8 Flash Liteに切り替えて続けます。声の自然さは少し下がり、毎日16〜17時ごろに3.8 Flashへ戻ります。切り替えたくないときは、設定の「無料枠を使い切ったとき」で外せます。3.8 Flash Liteも使い切ったら、Microsoftの声、それも使い切ったらElevenLabsの声で続けます（キーを入れたものだけ。作り方は上の「予備：ElevenLabsの声」「予備：Microsoftの声」）。どちらを先に使うかは、設定の「先に使う声」で選べます。Gemini以外の声で作った段落には、右上に「✓ Microsoftの声」「✓ ElevenLabsの声」と出ます。Geminiが戻ったあとに、読み上げ画面の「Geminiの声で作り直す」か、履歴の同じボタンを押すと、その段落だけGeminiの声に置き換えます
- **目次**：アルバムのように何話も入った台本は、読み上げ画面の「目次」から話を選んで、その話の頭へ移れます。再生中の話は下の表示とロック画面にも出ます。目次の各話の右にある「原文をコピー」を押すと、その話の元の文（■5行要約・あとがき・概要欄用タイトルも入ったまま）をコピーできます
- **履歴**：右上の時計のボタンで、これまで読み上げた文章の一覧が開きます。声の組み合わせごとに残り、タップすると続きから、保存済みの音声で再生します（聞き直しは無料）。名前の変更と削除もできます。「原文をコピー」を押すと、その文章をまるごと（要約やあとがきも入ったまま）コピーします。編集画面の「コピー」は、入力欄の文章をまるごとコピーします
- **ブックマーク**：再生画面の下のしおりのマーク（＋の付いたしおり）を押すと、聞いている話をブックマークします（アルバムは、その話だけ）。マークが青く塗られ、本文のその話の題名の左に小さなしおりが付きます。もう一度押すと外れます。目次の各話にあるしおりのマークでも、付けたり外したりできます。右上のしおりのボタンで一覧が開き、押すとその話の頭から聞けます。一覧の「原文をコピー」で、その話の元の文（要約やあとがきも入ったまま）をコピーでき、「消す」でブックマークを消せます。履歴から話を消すと、その話のブックマークも消えます
- **端末に保存**：読み上げ画面の上の「残りを保存」か、履歴の「端末に保存」を押すと、まだ作っていない段落をまとめて作ってiPhoneに保存します。すべて保存できると「✓ 端末に保存済み」と出て、インターネットにつながっていなくても、目次も含めて最後まで聞けます。保存済みの段落は、右上に小さな✓が付きます。すべて保存した履歴は、保存の上限を超えても消しません
- **順番待ちに入れる**：入力欄に次の話を貼り付けて「順番待ちに入れる」を押すと、聞いている話や書き出しはそのままで、上から順に作って端末に保存します。続けて何話でも入れられます（押すと欄が空になります）。入力欄の下に順番待ちの一覧が出て、「やめる」で外せます。無料枠を使い切るなどで止まったときは、「続ける」で残りだけを作ります。アプリを閉じても一覧は残り、次に開いたときに続きから作ります（止まった日のうちは、「続ける」を押すまで待ちます）
- **続けて次の話へ**：「順番待ちに入れる」で入れた話は、聞いている話が終わると、2秒ほどあけて入れた順に続けて流れます。履歴の「次に聞く」でも足せます（「次に聞くのをやめる」で外せます）。読み上げ画面の上に「この話のあとに続けて：〇〇」と出ます。最後の段落で「次へ」（ロック画面の「次へ」も）を押すと、すぐ次の話へ移ります。設定の「続けて聞く」で切れます
- **おやすみタイマー**：再生画面の月のマークを押して、「15分／30分／45分／60分で止める」か「この話の終わりで止める」を選びます。止めた位置は覚えているので、次は続きから聞けます。Macでは止まる前の15秒で音が少しずつ小さくなります（iPhoneはアプリから音量を変えられないので、そのまま止まります）
- **書き出し中も使える**：書き出しの画面を閉じても、書き出しは裏で続きます。できたら知らせるので、「保存する」からファイルに保存してください
- **音声ファイルに保存**：読み上げ画面の「書き出し」で1つのファイルにまとめ、「ファイル」アプリに保存できます（どちらもMP3。Geminiは1時間で約29MB）
- **画面ロック中に止まるとき**：ホーム画面のアイコンではなく、Safariのタブで開いて使ってください
- **保存した音声が消えるとき**：Safariのタブで使っている場合、このアプリを7日間開かないと、Safariが保存データを消すことがあります。ホーム画面のアイコンから使う場合は消されません

## 使っている部品

- MP3への圧縮には [lamejs](https://github.com/zhuker/lamejs)（LGPL-3.0）を使っています。初めて圧縮するときにjsDelivrから読み込み、その後は端末に保存した分を使います
