# よみこえ

AIの自然な声で、長い文章を読み上げるiPhone向けのWebアプリです。字数の上限はありません。
声は2種類から選べます。

| | Gemini（Google） | Grok（xAI） |
|---|---|---|
| 料金 | 無料（1日・1分あたりの回数に上限あり） | 100万字あたり15ドル |
| 声の数 | 30種類（女性14・男性16） | 26種類 |
| 表現の指示 | 間・息つぎ・ため息、読み方の雰囲気を言葉で指示 | 間・息つぎ・ささやき・ため息など |

## 使い始めるまで

### 1. APIキーを作る

**Geminiの場合（おすすめ・無料・カード不要）**

1. [Google AI Studio のAPIキーのページ](https://aistudio.google.com/apikey) をGoogleアカウントで開きます。
2. 「APIキーを作成」を押し、**「新しいプロジェクトで作成」**を選びます。
   お支払い情報（クレジットカード）を登録したGoogle Cloudのプロジェクトで作ると、無料枠ではなく有料になります。
3. 表示されたキー（`AIza` で始まる文字列）をコピーします。
4. その日に使える回数は、AI Studioの「使用量とレート制限」で確認できます。使い切ると、日本時間の16〜17時ごろに回復します。

**Grokの場合**

[console.x.ai](https://console.x.ai) でアカウントを作り、クレジットを購入してから「API Keys」でキーを発行します。

### 2. このフォルダをネットに置く（GitHub Pages・無料）

1. [github.com](https://github.com) でアカウントを作る
2. 新しいリポジトリを作る（Public）
3. 「uploading an existing file」から、このフォルダのファイルをすべてドラッグして保存
4. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
5. 数分後に表示される `https://〜.github.io/〜/` がアプリのURL

### 3. iPhoneに入れる

SafariでそのURLを開き、共有ボタン →「ホーム画面に追加」。

### 4. APIキーを入れる

アプリ右上の設定ボタンを開き、「音声の種類」を選んでキーを貼り付けます。キーはiPhoneの中にだけ保存され、GoogleやxAI以外には送られません。
Geminiは「読み方の雰囲気」に「静かに、低い声で語るように」のように書くと、声の調子が変わります。

## 料金の目安

- **Gemini**：無料。文字数ではなく、1日・1分あたりの回数に上限があります。回数を節約するため、2つ目以降は段落をまとめて大きめに送ります。
- **Grok**：1ドル150円なら、月1,000円で約44万字。設定の「月の上限」を超えそうになると、自動で止まります。
- どちらも、一度作った段落はiPhoneに保存されるので、聞き直しは無料です。
- アプリの数字は、このiPhoneで使った分から出した目安です。正確な金額はGoogle CloudやxAIの管理画面で確認してください。

## コツ

- **読み間違い**：設定の「読み方の辞書」に `怪異=かいい` のように登録
- **ルビ**：`漢字《かんじ》` や `｜漢字《かんじ》` の形式は、自動でルビの読みを使います
- **表現**：入力欄の下のボタンで指示を入れられます。ささやき・やわらかく・ゆっくりはGrokだけで使えます
- **台本**：「💴📙の題名」と「───」の区切り線がある台本は、題名と本文だけを読みます。■5行要約・■あとがき・■概要欄用タイトル（【短】【長】）などは飛ばします（設定の「台本の読み方」で変更でき、あとがきだけ読むこともできます）
- **履歴**：右上の時計のボタンで、これまで読み上げた文章の一覧が開きます。声の組み合わせごとに残り、タップすると続きから、保存済みの音声で再生します（聞き直しは無料）。名前の変更と削除もできます
- **音声ファイルに保存**：読み上げ画面の「書き出し」で1つのファイルにまとめ、「ファイル」アプリに保存できます（GrokはMP3、GeminiはWAV。WAVは1時間で約170MBと大きめです）
- **画面ロック中に止まるとき**：ホーム画面のアイコンではなく、Safariのタブで開いて使ってください
